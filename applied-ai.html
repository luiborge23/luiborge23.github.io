Applied AI · Technical program management

Putting AI to work in real workflows.

Taking AI-enabled analysis and automation from a defined pilot through evaluation and operational use.

Senior Technical Program ManagerAnalysis, reporting & benchmarking workflows

The challenge

Analysis and reporting can consume the time teams need for investigation and decisions. The opportunity was to use AI in defined workflows—not to add a tool without a clear purpose.

My contribution

  • Led an AI agents and Python SDK pilot from scope definition to a formal go/no-go readout.
  • Built AI-enabled analysis workflows using retrieval, language models, and prompt-driven reporting.
  • Delivered production AI capabilities for analysis, reporting, benchmarking, and lab monitoring.
  • Developed self-service tools to make recurring analysis more accessible to partner teams.
Define

Choose a real workflow and a clear scope.

Evaluate

Run the pilot and review the evidence.

Operationalize

Move useful capabilities into everyday work.

The outcome

From pilot to production

The TPM résumé records a GO recommendation and production AI workstreams. The product-management résumé describes selected analysis and reporting cycles improving from days to minutes; no universal speedup is claimed.

Working principle

Start with the work that needs to improve. Evaluate the result before expanding the solution.
